AI Post Generator

AI Post Generator is a simple and user-friendly web application that helps users create engaging and detailed social media posts in seconds.

The application is built using HTML, CSS, and JavaScript and provides different platforms, tones, and languages to make post creation easier.

How to Use
Open the AI Post Generator website.
Enter a topic in the topic box.
Select your desired platform.
Select the tone of the post.
Select the language.
Click Generate Post.
Your detailed social media post will appear in the result section.
Click Copy to copy the generated post.
Example

Enter a topic:

Launching my new online business


Select:

Platform: Instagram
Tone: Professional
Language: English


Then click:

Generate Post


The application will generate a detailed social media post with multiple paragraphs and relevant hashtags.

GitHub Pages Deployment

This project can be deployed for free using GitHub Pages.

Deployment Steps
Create a GitHub repository named:
AI-Post-Generator

Upload these files:
index.html
app.js
styles.css
README.md


Open the repository Settings.

Select Pages from the left sidebar.

Under Build and deployment, select:

Source: Deploy from a branch
Branch: main
Folder: / (root)


Click Save.

Wait a few moments for GitHub to deploy the website.

Your live website will be available at:

[https://almeerahmed610/AI-Post-Generator/](https://github.com/almeerahmed610/AI-Post-Generator)


Replace almeerahmed610 with your GitHub username.
